MarkPress turns a folder of Markdown files into a website. Write a page, push it to GitHub, and Jenkins builds, tests and publishes the site within a minute.

## What you are looking at

Every page on this site started as a plain `.md` file in the `content/` folder. The footer of each page shows which Jenkins build produced it, so you can see a new push go live.
